# 全息圖數字位置紀錄

這份文件固定每個節點的計算來源與解析角色。數字本身的特質由
`src/features/results/interpretations.ts` 提供；位置定義則由
`src/features/results/position-profiles.ts` 提供。解析時必須同時考慮
「位置功能」與「落入該位置的數字」，不可只套用單一數字關鍵字。

## 原始生日層

- A「出生日十位」：日期第一碼；觀察早期反應與行動起點。
- B「出生日個位」：日期第二碼；觀察日常反應與個人表現。
- C「出生月十位」：月份第一碼；觀察情境接收與關係背景。
- D「出生月個位」：月份第二碼；觀察互動需求與適應方式。
- E「出生年千位」：年份第一碼；觀察世代背景的起始特質。
- F「出生年百位」：年份第二碼；觀察世代環境的承接方式。
- G「出生年十位」：年份第三碼；觀察成長階段的內在傾向。
- H「出生年個位」：年份第四碼；觀察個人經驗的落實方式。

## 四組基礎

- I「日期基礎」＝ A＋B：直覺啟動與第一反應。
- J「月份基礎」＝ C＋D：關係互動與情境適應。
- K「年份前段」＝ E＋F：世代脈絡與外部要求。
- L「年份後段」＝ G＋H：長期節奏與經驗累積。

## 核心整合

- M「個人經驗整合」＝ I＋J：個人需求與關係經驗的整合。
- N「長程經驗整合」＝ K＋L：環境脈絡與長期經驗的整合。
- O「核心主性格」＝ M＋N：判斷、選擇與自我定位的核心模式。

## 表達與發展

- P「個人面向表達」＝ M＋O：核心特質在個人與熟悉情境中的表達。
- Q「社會面向表達」＝ N＋O：核心特質在工作與外部情境中的表達。
- R「整體整合方向」＝ P＋Q：內外表達協調後的發展方向。

## 左右側翼

- X「日期延伸」＝ I＋M：行動本能經整合後的延伸反應。
- W「月份延伸」＝ J＋M：關係需求經整合後的延伸反應。
- S「個人側翼」＝ X＋W：私人生活與親近關係中的綜合模式。
- V「年份前段延伸」＝ K＋N：面對制度、責任與環境要求的延伸反應。
- U「年份後段延伸」＝ L＋N：面對長程目標與經驗累積的延伸反應。
- T「社會側翼」＝ V＋U：工作、團體與公共情境中的綜合模式。

## 解讀原則

1. 先讀位置功能，再套入該位置的數字特質。
2. 核心節點不等於全部人格；基礎、表達與側翼用來補充不同情境。
3. 相同數字落在不同位置時，應依該位置角色改寫，不可重複同一句描述。
4. 成對位置應比較其一致與差異，例如 M／N、P／Q、S／T。
5. A–H 是原始資料層，主要用於追溯來源；主要解析優先讀 I–T 的衍生結構。
